1. Activar la sincronización por red
Por defecto, Debian administra el tiempo con la herramienta timedatectl. Para obligar al sistema operativo a usar NTP de forma automática, abrí la terminal y ejecutá:

sudo timedatectl set-ntp true

2. Configurar servidores NTP de Argentina
Para que la sincronización sea rápida y con la menor latencia posible, conviene apuntar a los servidores locales en lugar de los globales.

Abrí el archivo de configuración con tu editor de texto: sudo nano /etc/systemd/timesyncd.conf

Buscá la línea que dice #NTP= y borrá el símbolo # para descomentarla.

Modificala para que quede exactamente así: NTP=ar.pool.ntp.org

Guardá los cambios (en nano usás Ctrl+O, Enter, y luego Ctrl+X).

Reiniciá el servicio para aplicar la nueva ruta: sudo systemctl restart systemd-timesyncd

3. Ajustar la zona horaria local
El protocolo NTP solo sincroniza la hora global (UTC). Para que tu código en Python registre bien los horarios, el sistema operativo debe saber en qué parte del mundo está.

Configurá la zona horaria correcta ejecutando: sudo timedatectl set-timezone America/Argentina/Cordoba

4. Verificar el estado del reloj
Para confirmar que tu Debian ya está atado al servidor NTP de internet y sincronizando correctamente, tirá este último comando:

timedatectl status

Revisá que el renglón NTP service: diga active y que System clock synchronized: diga yes.
